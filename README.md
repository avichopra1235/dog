# Definition of Gurjar — Landing Page

Static, Vercel-ready landing page for Hitman's "Definition of Gurjar".

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Framework preset: **Other** (or leave auto-detected).
4. Build command: leave blank.
5. Output directory: leave blank.
6. Deploy.

Or drag the folder into a Vercel deployment flow.

## Files
- `index.html` — complete responsive landing page
- `assets/cover.jpg` — supplied cover art
- `assets/promo.jpg` — supplied promotional visual
- `assets/background.jpg` — supplied background reference
- `assets/visual.gif` — generated animated background visual
- `assets/rebel-talents-logo.png` — transparent version of supplied logo
- `assets/favicon.png` — favicon

The Spotify player is embedded from the supplied release link. Apple Music is provided as a secondary streaming button.
